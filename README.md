# Handwriting Recognition and Replication with Thymio
> **Course:** Mobile Robots (RM) — Master's in Informatics Engineering (MEI)
> **Institution:** Faculty of Sciences, University of Lisbon (Ciências ULisboa)
> **Instructor:** Prof. João Carvalho

---

## Project Overview
This project aims to develop an autonomous system where a *Thymio* mobile robot recognizes handwritten text captured via a webcam and physically replicates the identified characters by drawing trajectories on a sheet of paper.
